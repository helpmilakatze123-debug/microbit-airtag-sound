# Custom Audio for micro:bit V2

Custom audio extension containing three embedded PCM sounds.

## Sounds

- power-on
- alarm
- anti-stalking

## Audio format

The RAW files must be:

- 8000 Hz
- mono
- unsigned 8-bit PCM

## Blocks

The extension provides:

- play power-on sound
- play alarm sound
- play anti-stalking sound

## Important

This extension is intended for micro:bit V2 / CODAL.
